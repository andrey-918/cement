# СМ Групп - Поставка цемента из Ирана в Россию

## Описание проекта

Это веб-сайт компании ООО «СМ ГРУПП», официального представителя Иранского завода PJSC «Bojnurd Cement Company». Сайт представляет услуги по поставке высококачественного портландцемента типа ЦЕМ 0, класс прочности 42,5Б (аналог М500), соответствующего ГОСТ 31108-2020 и Европейскому стандарту CEM I 42,5R EN 197-1:2011.

### Основные возможности сайта:
- Информационные разделы о преимуществах, маршруте поставки, технических деталях
- Интерактивная карта маршрута доставки
- Контактная информация и реквизиты компании
- Адаптивный дизайн для мобильных устройств
- Анимации с использованием Framer Motion

## Технологии

### Frontend
- **React 19** - основная библиотека для создания пользовательского интерфейса
- **TypeScript** - типизированный JavaScript для повышения надежности кода
- **Vite** - быстрый инструмент сборки и разработки
- **Framer Motion** - библиотека для анимаций
- **React Router DOM** - для навигации (если потребуется в будущем)

### Стилизация
- **CSS3** - кастомные стили с использованием CSS Variables
- Адаптивный дизайн с мобильной версткой
- Dark mode

### Инструменты разработки
- **ESLint** - линтинг кода
- **Prettier** - форматирование кода

## Установка и запуск

### Предварительные требования
- Node.js (версия 16 или выше)
- npm или yarn

### Установка зависимостей
```bash
cd frontend
npm install
```

### Запуск в режиме разработки
```bash
npm run dev
```
Приложение будет доступно по адресу `http://localhost:3000`

### Сборка для продакшена
```bash
npm run build
```
Собранные файлы будут находиться в папке `dist`

### Предварительный просмотр сборки
```bash
npm run preview
```

## Скрипты

В файле `package.json` определены следующие скрипты:

- `dev` - запуск сервера разработки
- `build` - сборка проекта для продакшена
- `preview` - предварительный просмотр собранного приложения
- `test` - запуск тестов (пока не настроено)

## Разработка

### Архитектура
Проект построен на компонентной архитектуре React с использованием:
- **Функциональных компонентов** с хуками
- **TypeScript** для типизации
- **Framer Motion** для анимаций
- **Модульной структуры** стилей

### Ключевые компоненты
- `App.tsx` - корневой компонент
- `Home.tsx` - главная страница с композицией секций
- Компоненты секций в `sections/` - отдельные блоки контента
- `Header.tsx` и `Footer.tsx` - компоненты макета

### Стилизация
- Используются CSS модули и переменные
- Адаптивный дизайн с мобильной версткой
- Кастомные анимации через Framer Motion
